# Pixel Castle Interior Tileset (16x16)
83 free pixel-art tiles and sprites for medieval castle interiors: floor (18), walls (23), props (34), characters (8).
- PNG/native = 16x16, PNG/x4 = 64x64 (nearest-neighbor)
- spritesheet.png + spritesheet.json (x, y, w, h per frame), tileset.png (floors+walls), sample_scene.png
Engines: Unity, Godot, GameMaker, RPG Maker, Construct, Phaser, Pygame, LOVE. Use Point/Nearest filtering, no compression, integer scaling.
